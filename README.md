# KGLGANSynergy: Knowledge Graph-Based Local and Global Attention Network for Drug Synergy Prediction

![frame](README.assets/frame.png)

**The architecture of KGLGANSynergy.** (1) Knowledge Graph Construction: A knowledge graph is built based on interactions among drugs, cell lines, proteins, and tissues. (2) Local Graph Attention Network (LGAT): Local feature representations are generated by aggregating neighborhood information through message passing and attention mechanisms. (3) Global Graph Attention Network (GGAT): Attention mechanisms establish dynamic dependencies among all nodes in the graph, enabling each node to integrate global contextual information and output global feature representations. (4) Mutual Cross Attention (MCA): A bidirectional attention mechanism adaptively fuses local and global features to produce the final representation of each node. (5) Drug Synergy Prediction: The features of drug and cell line entities are combined using max pooling and inner product operations, and a sigmoid function is applied to compute the predicted probability of synergy.

# Data_set

  - DrugCombDB: The DrugCombDB dataset and its corresponding knowledge graph.
  - OS: The Oncology-Screen dataset and its corresponding knowledge graph.

# Source codes

  - load_data.py: Data loading function.
  - main.py: Leave-one-drug-pair-out split training function.
  - main_r.py: Random split training function.
  - model.py: Model files of KGLGANSynergy.
  - parse.py: Hyperparameter configuration files for the DrugCombDB and Oncology-Screen datasets.
